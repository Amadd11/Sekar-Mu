# Design System
## Direction
Modern, professional, academic, medical, clean, accessible.

## Colors
Primary #0F766E (Teal)
Secondary #2563EB (Blue)
Success #16A34A
Warning #EA580C
Danger #DC2626
Neutral: Slate scale

## Typography
Inter

## Components
Button, Card, Stepper, Status Badge, Data Table, Form Field, Upload Card, Modal, Alert, Progress indicator.

## Application Flow UI
Application → Information → Profile → Assessment → Protocols → Documents → Submit
