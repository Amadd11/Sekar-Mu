# Product Requirements Document — Sekar-Mu

## Vision
Sekar-Mu adalah aplikasi web untuk mengelola pengajuan, evaluasi, dokumen, protokol penelitian, review, dan pelaporan secara terintegrasi.

## Roles
### Admin
User management, application management, reviewer assignment, monitoring, reports.

### Applicant
Create application, fill information/profile, self assessment, research protocols, upload documents, submit, track status.

### Reviewer
View assigned applications, review documents, assess, comment, recommend, request revision, approve/reject according to authorization.

## Application Lifecycle
Draft → Submitted → Under Review → Revision Required → Resubmitted → Approved/Rejected

## Modules
Authentication, Dashboard, Application, Application Information, Application Profile, Self Assessment, Research Protocol, Documents, Review, Reports.

## MVP
Phase 1: Auth, roles, dashboard, application, information, profile.
Phase 2: self assessment, protocols, documents.
Phase 3: reviewer, review, revision, approval.
Phase 4: reports and notifications.
