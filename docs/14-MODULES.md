# Module Specification
## Application
Create, update, view, delete, submit, status tracking.

## Information
Manage application information.

## Profile
Manage institution/KEPK profile data.

## Self Assessment
Sections → groups → items → answers. Answers can contain score, comment, evidence.

## Research Protocol
CRUD for research protocols.

## Document
Upload, replace, delete, download, authorization.

## Review
Assignment, review, comments, revision, approval, rejection.
