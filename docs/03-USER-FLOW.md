# User Flow

## 1. Flow Ketua KEPK & Anggota KEPK
1. **Login & Dashboard**: Melihat ringkasan metrik kepatuhan, status hasil akreditasi, dan progress 5 bagian standar.
2. **Evaluasi Diri (164 Butir)**: Mengisi skor mandiri (A/B/C/D), catatan keterangan, dan mengunggah dokumen bukti dukung secara bersamaan (1 berkas = Belum Lengkap, $\ge 2$ berkas = Lengkap).
3. **Berkas Dokumen**: Memantau dan mengunduh seluruh dokumen bukti terunggah yang dikelompokkan per bagian evaluasi (A s/d E) dengan pencarian live dan filter status.
4. **Hasil Akreditasi**: Memantau hasil telaah, status akreditasi resmi, skor kepatuhan, dan ulasan rekomendasi asesor secara real-time.

## 2. Flow Asesor Akreditasi
1. **Login & Portal Asesor**: Memantau daftar berkas KEPK yang ditugaskan beserta status evaluasinya.
2. **Lembar Penilaian (Workbench)**: Menelaah evaluasi diri 164 butir, memeriksa berkas lampiran KEPK, memberikan skor verifikasi independen (A/B/C/D), catatan temuan, serta tingkat kekuatan bukti.
3. **Rekomendasi Akreditasi**: Mengisi kesimpulan dan label rekomendasi resmi (*Terakreditasi*, *Perlu Tindakan Perbaikan*, atau *Tidak Lolos*).

## 3. Flow Administrator (Super Admin)
1. **Login & Dashboard**: Memantau statistik seluruh berkas KEPK, progress hasil penilaian, dan status penugasan asesor.
2. **Tugaskan Penilai**: Menugaskan satu atau lebih asesor penilai ke permohonan akreditasi KEPK.
3. **Keputusan Akhir Akreditasi**: Mengesahkan status akreditasi permohonan (**ACC / Terakreditasi** atau **Tolak / Tidak Lolos**).
4. **Kelola Sistem**: Menambah/mengedit akun pengguna dan mengelola kriteria instrumen 164 butir.
